# sticker/ —— 表情包模块

本地表情包目录 + 语义标签 + 情绪匹配，输出 CQ `image` 段（base64://，NapCat 最通用）。

| 文件 | 职责 |
|---|---|
| `index.mjs` | `StickerEngine`（扫描/匹配/搜索/自动重扫）+ `createStickerModule`（hooks + 命令） |

## 标签来源（三处合并）

1. **子目录名**：`开心/happy.png` → 标签「开心」；
2. **tags.json**（放在表情包目录根）：`{ "plain.png": ["无语", "随便"] }`；
3. **文件名**：`干饭_好吃.png` → 标签「干饭」「好吃」。

## 匹配逻辑

- 回复文本命中**内置情绪词表**（开心/难过/生气/撒娇/惊讶/晚安/干饭）→ 该情绪池里随机一张，**必发**；
- 未命中 → 按 `sticker.rate`（默认 0.2）概率全池随机；
- `/表情 [关键词]` → 按文件名/标签搜索随机发一张；不带词随机发；空库给引导文案。

## 配置对应

`sticker.enabled` / `sticker.dir`（留空 = 插件家目录 `stickers/`）/
`sticker.rate`（0~1）。目录每 5 分钟自动重扫，新图不用重启。

> 建议：目录里按「开心/难过/生气…」建子文件夹，配合文件名描述，效果最好。
